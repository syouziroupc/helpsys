HOW IT WORKS

認識性能を上げても、安全境界は崩さない。

01

ローカルで状態を把握

UI Automation、前面アプリ、ブラウザー状態、画面遷移を組み合わせ、検索欄・Windows検索・Startメニューなどの役割を端末内で判断します。

02

Privacy Gateで送信可否を判断

Password、OTP、Token、API Key、Cookie/Storage、金融認証などをローカルで遮断します。安全判定に失敗した場合も送信しません。

03

利用者自身が操作

HelpSysは操作場所を示しますが、クリック・入力・支払い・認証は自動実行しません。操作後の状態を再取得してから次の案内へ進みます。

SECURITY BY DEFAULT

安全版の防御を標準化。

単一の送信経路画面由来のクラウド要求はPrivacy Gateを通り、HTTP通信はCloud AI Adapterへ集約します。
通信先を固定外部通信はHelpSysの承認済みHTTPS originへ限定し、リダイレクト・Cookie・OSプロキシ継承を無効化します。
生の入力値を送らない入力欄の内容は保持せず、必要な場合も入力有無や検索欄の役割など最小限の状態だけを利用します。
AI判断を切替可能無法者版では Auto / GLM を利用できます。Geminiは現在サーバー側未設定のため無効化しています。
音声は明示開始時のみ音声認識は音声ボタン、またはローカルの起動語で利用者が開始した場合だけクラウド文字起こしへ進みます。

SEPARATE UPDATE CHANNELS

通常版と無法者版は別系統です。

通常版 A3 は preview-latest、無法者版は outlaw-latest を使用します。実行ファイルと更新パッケージの両方でチャネル情報を確認し、別系統の更新パッケージは拒否します。

LATEST DOWNLOAD

/download は常に最新版。

/download は通常版の HelpSys-latest-win-x64.zip、/download/outlaw は無法者版の HelpSys-Outlaw-latest-win-x64.zip に固定されています。両者の更新チャネルは共有しません。
